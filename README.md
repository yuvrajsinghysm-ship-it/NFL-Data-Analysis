# NFL-Data-Analysis
An interactive Power BI dashboard for monitoring fertilizer plant operations, analyzing production performance, equipment status, maintenance activities, energy efficiency, downtime, and safety metrics using a realistic industrial dataset.


🏭 NFL Nangal Plant Operations Dashboard

An end-to-end industrial analytics project built using Python and Power BI to monitor and analyze key operational metrics of a fertilizer manufacturing plant. The project transforms raw operational data into an interactive dashboard that helps visualize production trends, equipment performance, maintenance activities, energy efficiency, downtime, and safety incidents.

🚀 Features
📊 Executive KPI Dashboard
📈 Monthly Production Trend Analysis
🏭 Department-wise Production Performance
⚙️ Equipment Status Monitoring
👷 Shift-wise Production Analysis
🔧 Maintenance Activity Analysis
⏱️ Downtime Analysis by Department
🚨 Safety Incident Monitoring
📋 Department Performance Summary Table
🎨 Custom NFL-themed dashboard design
🛠️ Tech Stack
Power BI

Pandas
NumPy
Power Query
DAX (Basic Measures)
📂 Dataset
10,000 simulated industrial records
Production & Target Metrics
Equipment Status
Maintenance Records
Energy & Steam Consumption
Downtime Data
Shift Information
Safety Incidents
Department-wise Operations
🎯 Project Objective

To build an interactive operations dashboard that enables plant managers to monitor production performance, identify operational bottlenecks, track maintenance activities, and support data-driven decision-making.
